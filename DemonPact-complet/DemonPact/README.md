# DemonPact - Paper 26.3 (tout-en-un)

Contenu : pom.xml, plugin.yml, config.yml, dialogues.yml, un seul fichier source
(src/main/java/fr/demonpact/DemonPactPlugin.java) et le workflow GitHub Actions.

Compiler : JDK 25 + Maven, mvn clean package -> target/DemonPact.jar (ou poussez sur GitHub : l Action compile).
Installer : jar dans plugins/, puis /demon setstell au centre voulu (construit le temple), /demon conditions, /demon stell.

Nouveautes : tete 33 pour cent a la mort (delai 250 s), deguisement par clic droit sur une tete (1h30, /undeguise),
remboursement des coeurs a l abandon, vol de coeur 15 pour cent (delai 480 s), apparition auto toutes les 2 h
(le premier qui parle au demon recoit le pacte), temple demoniaque grec.
Le code n a pas ete compile contre l API Paper 26.3 lors de sa redaction : seule la syntaxe a ete validee.
